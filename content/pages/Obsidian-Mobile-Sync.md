## Google Drive
Способ рабочий если монтировать Google Drive как сетевой диск, но для этого нужен root с termux, а не всегда хочется рутить свой телефон :( 
Не работает на IOS

## iCloud 
Работает отлично, на MacOS можно достать где-то в ~/Library просто как папку. Экосистемным icloud-истам рекомендую.

## Termux Git Sync
Можно настроить синк через termux на андроид. 
Полный стек будет termux + git + git-crypt + скрипты для синка или плагин Git. Бывают конфликты, но с этим можно научиться работать. Особенно напрягают конфиликты в .obsidian.
